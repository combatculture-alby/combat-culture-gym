# Combat Culture Gym

Browser-based martial arts gym management game.

- [Production game](https://combatculture-alby.github.io/combat-culture-gym/)
- [Garage hub development preview](https://combatculture-alby.github.io/combat-culture-gym/garage/)
- [Garage progression and visual QA (draft PR #31)](https://github.com/combatculture-alby/combat-culture-gym/pull/31)

The garage preview is built from `feat/garage-level-one` and keeps its save data separate from production.

## Garage preview: room and doorway QA

The independent [garage hub preview](https://combatculture-alby.github.io/combat-culture-gym/garage/) includes side-view horizontal stairways, redesigned outdoor gates, and secondary-room side floors that are walkable but do not accept equipment placement. These revisions remain isolated in the draft development branch and do not alter production gameplay.
