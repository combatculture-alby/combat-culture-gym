# Upload approved source PNGs here

This directory is for **original approved concept sheets**, not cropped gameplay sprites.

Upload the PNG files from `combat-culture-levels-1-2-approved-source-art.zip` into this directory using GitHub's **Add file → Upload files** on branch `release/levels-1-2`. Unzip first; GitHub does not unpack uploaded ZIPs.

Keep original files intact for visual comparison. The two recently supplied sheets should be named:
- `Player Coach Approved.png`
- `Holly Approved (sheet says Erin).png`

The text **Erin** on the latter sheet is an artwork label error; the character in the game is **Holly**.

Do not delete existing `src/assets` graphics until their replacements have been extracted, visually checked, and tested.
