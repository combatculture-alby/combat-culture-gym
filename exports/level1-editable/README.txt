Combat Culture Gym - editable native Level 1 sprite pack

These are exported from the ORIGINAL PNG data embedded in the approved
Level 1 build, NOT cropped from the screenshot.

Use files in edit-8x/ to edit large, pixel-sharp images. Keep the
pixel grid, transparency and original overall proportions.
Files in original/ are the exact original-resolution artwork.
edit-4x/ provides a smaller editing option.

The game uses native pixel-art dimensions. Upscaling with nearest-
neighbor makes editing easier but does not invent additional detail.
Edited 8x PNGs can be resized down to native size for integration.

The wall is supplied as REFERENCE ONLY.
