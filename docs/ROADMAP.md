# Combat Culture Gym — Development Roadmap

## Milestone 1: Foundation
Phaser + TypeScript + Vite, basic scene boot, asset loader, local dev/build scripts. Verify production build and no runtime errors.

## Milestone 2: Gym movement
Small map, owner sprite, keyboard movement, click-to-move, simple pathfinding and collision, interaction prompts. Verify reachable interactions and blocked paths.

## Milestone 3: Students and schedule
Four NPCs, deterministic attendance, simple dialogue, class start/end state. Verify students arrive and leave consistently.

## Milestone 4: Class Rush
Three task types, 45–60-second session, patience, scoring, results, hybrid controls. Verify completion even with missed tasks.

## Milestone 5: Progression and saves
Money, reputation, skill changes, day advance, versioned local save, restore and developer reset. Verify reload and no duplicate class rewards.

## Milestone 6: Polish and private playtest
Representative art, animations, UI readability, accessibility, desktop browser QA, five-day playtest. Iterate on fun before scope expansion.

## Release direction
Later: Pad Work, Coach Says, customization, expansion, mobile controls, save import/export, deployment to combatcultureusa.com.

## Rules
Inspect existing files before edits; small commits; test before declaring success; maintain backward-compatible saves; avoid unnecessary dependencies. Never claim browser behavior verified solely because code was written.
